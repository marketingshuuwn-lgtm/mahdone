# مهد — إدارة المهام (React + Supabase)

إعادة بناء كاملة لتطبيق "مهد" الأصلي (HTML/JS واحد + LocalStorage) كتطبيق React
احترافي مقسّم إلى مكوّنات، مع استبدال التخزين المحلي بقاعدة بيانات **Supabase**
(Postgres) مع تحديث لحظي (Realtime) بين كل الأجهزة المتصلة.

## المزايا المحافَظ عليها من النسخة الأصلية
- مصفوفة أيزنهاور (مهم/مستعجل) بالسحب والإفلات
- عرض الخط الزمني وعرض مخطط جانت لأسبوع قادم
- لوحة تقارير وإحصائيات (KPIs)
- المهام المعلقة
- تصنيف المهام إلى مساحة عمل/شخصي مع فلترة وتقارير
- مهام فرعية Checklist داخل كل مهمة مع شريط تقدّم مختصر
- إعداد أيام العمل للتكرار اليومي (افتراضياً الأحد–الخميس)
- إشعارات متصفح محلية: ملخص صباحي ومراجعة مسائية عندما يكون التبويب مفتوحاً
- إضافة سريعة + "مساعد ذكي" يفهم كلمات مثل (اليوم، بكرة، بعد أسبوع)
- الوضع الليلي/النهاري
- تصدير/استيراد المهام (CSV و Excel)

## الفرق الأساسي
كل عملية (إضافة، تعديل، حذف، سحب) تُكتب الآن مباشرة في قاعدة بيانات Supabase
بدل `localStorage`، وأي جهاز آخر مفتوح على نفس المشروع يرى التحديث فوراً
بفضل Supabase Realtime.

## خطوات التشغيل

### 1. إنشاء مشروع Supabase
1. أنشئ حساباً/مشروعاً على https://supabase.com (مجاني للبداية)
2. من **SQL Editor** داخل لوحة التحكم، افتح الملف `supabase/schema.sql`
   الموجود في هذا المشروع، والصق محتواه بالكامل ثم نفّذه (Run)
   — سينشئ جدول `tasks` مع صلاحيات الوصول ويفعّل التحديث اللحظي
   — إذا كان لديك مشروع قديم، أعد تشغيل الملف نفسه لإضافة أعمدة التحديثات مثل `context` بأمان

### 2. ضبط بيانات الاتصال
1. من **Project Settings > API** انسخ:
   - `Project URL`
   - `anon public key`
2. انسخ ملف `.env.example` باسم `.env` في جذر المشروع وضع القيمتين:
   ```
   VITE_SUPABASE_URL=...
   VITE_SUPABASE_ANON_KEY=...
   ```

### 3. التشغيل محلياً
```bash
npm install
npm run dev
```
ثم افتح الرابط الذي يظهر (عادة http://localhost:5173)

### 4. البناء للنشر
```bash
npm run build
```
سينتج مجلد `dist` جاهز للرفع على أي استضافة (Vercel، Netlify، Cloudflare Pages...)

## ملاحظة أمنية
سياسة الصلاحيات (RLS) في `schema.sql` تسمح حالياً بالوصول الكامل لأي شخص
يملك مفتاح `anon` (مناسب لتطبيق شخصي أو فريق صغير موثوق بدون تسجيل دخول).
إن رغبت لاحقاً بإضافة تسجيل دخول (Supabase Auth) بحيث تكون مهام كل مستخدم
خاصة به، أخبرني وسأضيف عمود `user_id` وأعدّل السياسات وواجهة الدخول.

## هيكل المشروع
```
src/
  lib/supabaseClient.js     إعداد اتصال Supabase
  hooks/useTasks.js         كل عمليات القراءة/الكتابة + الاشتراك اللحظي
  hooks/useToast.jsx        نظام التنبيهات المنبثقة
  utils/dateUtils.js        تنسيق التواريخ + محلل النص الذكي
  utils/importExport.js     تصدير/استيراد CSV و Excel
  components/               كل مكوّنات الواجهة (لوحة، خط زمني، جانت، تقارير، إعدادات...)
  App.jsx                   الشاشة الرئيسية وربط كل شيء
supabase/schema.sql          الجدول وسياسات الصلاحيات
```
